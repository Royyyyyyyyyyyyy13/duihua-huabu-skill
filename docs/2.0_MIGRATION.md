# 2.0 兼容说明

## 数据迁移

2.0 使用 `schemaVersion: 2`。旧 session 第一次由 2.0 打开时：

1. 原文件旁生成 `schema-<旧版本>-backup-<时间>.json`。
2. 节点、连线、位置和组装顺序原样保留。
3. 缺失的结构化详情使用摘要生成兜底内容，并标记 `contentQuality=fallback`。
4. 补充 `revision`、`contentRevision`、`viewState`、迁移记录和插件版本字段。
5. 讨论节点位置增加 `positionMode=auto|manual`。

迁移只在数据结构确实变化时写回，不会每次打开都重复备份。

## 并发安全

- 每个 session 使用独立锁文件。
- 写入先落到同目录临时文件，刷新磁盘后原子替换正式文件。
- stale 锁会自动清理。
- 布局、连线、组装区和节点更新使用局部原子修改，避免覆盖同时到达的新 checkpoint。

## 还原与撤销

还原画布只重排已有节点并重建默认主线。撤销还原时，如果还原后又生成了新节点，新节点及其关系仍会保留。

## 回退

需要人工回退时先停止画布服务，保留当前文件，再选用同目录的迁移备份。备份属于用户数据，不会被插件自动删除。
